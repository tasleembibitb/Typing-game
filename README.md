# Typing Game

A small typing game built with HTML, CSS and JavaScript.

**Built by Tasleem Bibi** — BSCS student, Begum Nusrat Bhutto Women University, Sukkur, Pakistan.

## How to play

1. Click **Start** — a random sentence is shown.
2. Type that sentence in the text area as fast as you can.
3. Click **Done** — the game shows your time in seconds and your score (correct words out of total words).
4. Click **Start** again to play another round with a new random sentence.

The word list includes sentences about programming and studying, including "Welcome to BNBWU Sukkur".

## How to run

No build step and no server needed:

1. Download / clone this repository.
2. Open `index.html` in any browser (double-click it).
